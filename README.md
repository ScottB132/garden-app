# Garden Advice App

## About

Garden Advice App is a Python-based command-line application that provides personalised gardening advice based on the user's selected season and plant type. The application also automatically detects the current month and displays relevant seasonal gardening tips to help users maintain a healthy and productive garden throughout the year.

The project demonstrates key Python programming concepts including:

- Input validation
- Dictionary-based data management
- Modular function design
- Use of docstrings and code documentation
- Date and time handling with the datetime module
- Clean and maintainable code structure

### Features

- Personalised gardening advice based on season and plant type
- Automatic season detection using the current month
- Seasonal gardening tips tailored to the time of year
- User-friendly command-line interface
- Well-documented and modular codebase
- Easy to extend with additional plants, seasons, and advice

### Future Improvements

- Internationalisation and multi-language support
- Graphical user interface (GUI)
- External data storage using JSON or CSV files
- Additional plant categories and gardening tips
- More advanced personalised recommendations

### Technologies Used

- Python 3
- Built-in datetime module

### Learning Objectives

This project was developed to practise Python fundamentals, improve code organisation, implement input validation, and demonstrate the use of functions, dictionaries, and structured documentation in a real-world application.
